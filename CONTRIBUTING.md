# Contributing to N/L Foundry website

Thank you for contributing to the public site.

## Development workflow

- Install dependencies with `npm install`.
- Run checks with:
  - `npm run check`
  - `npm run build`
  - `npm run verify:build`
- Make changes and keep route-safe, deterministic links.
- When working on content, prefer `src/content/docs` over ad-hoc pages.

## Repository standards

- Keep the site static and dependency-light.
- Keep all external dependencies obvious and justified.
- Prefer typed content and component-based structure over page-level duplication.
- Avoid adding third-party tracking, analytics, or cookie-based behavior.

## Review checklist

- Confirm `dist/index.html` is generated by the final build.
- Confirm homepage links resolve at `/`.
- Verify no `kevindraai.github.io/nlfoundry-site` references remain.
